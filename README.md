# CodeAlpha_PhishingAwarenessTraining

Phishing Awareness Training built for the **CodeAlpha Cybersecurity Internship (Task 2)**. It teaches non-technical people how to recognize phishing, understand social engineering, and respond safely.

**Live quiz:** https://YOUR-USERNAME.github.io/CodeAlpha_PhishingAwarenessTraining/

## What is inside

| Item | Description |
|---|---|
| `presentation/*.pptx` | 19-slide training deck with speaker notes |
| `presentation/*.pdf` | PDF version for quick viewing |
| `index.html` | Interactive 8-question quiz (HTML, CSS and JavaScript only) |

## Topics covered

1. Why phishing matters (statistics)
2. The phishing attack lifecycle
3. Types: email, spear phishing, whaling, smishing, vishing, quishing
4. Anatomy of a phishing email, with red flags
5. Spotting fake websites (typosquatting, subdomain tricks, HTTPS myth)
6. Smishing and vishing examples
7. Social engineering tactics (urgency, fear, authority, pretexting and more)
8. Real-world cases: Google/Facebook invoice fraud, Twitter 2020, Target 2013, BEC
9. The S.T.O.P. check (Sender, Tone, Ask, Path)
10. Best practices for individuals and organizations
11. Incident response: what to do if you clicked
12. Spot-the-phish exercise and interactive quiz

## How to use
